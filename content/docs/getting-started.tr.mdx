## Ne Çalıştırmak Üzeresiniz

AIVEX modüler bir yapay zeka araştırma çalışma zamanıdır. Piyasa verilerini, haberleri ve teknik sinyalleri alır,
yönetilen bir boru hattından geçirir ve Eye REST API aracılığıyla denetlenebilir araştırma çıktıları üretir.
Her çıktı `trace_id`, güven skoru ve kaynak atıfı taşır.

> **Özel Depo Bildirimi:** AIVEX şu anda özel, dahili bir çalışma zamanıdır.
> Genel depo erişimi mevcut değildir.
> AIVEX kod tabanına veya çalışma zamanına erişim talep etmek için [ekiple iletişime geçin](/contact).

## Ön Koşullar

- Python 3.11 veya 3.13
- MySQL 8.0+ (yerel veya uzak)
- Gerekli ortam değişkenlerini içeren bir `.env` dosyası (aşağıya bakın)

## Kurulum

Depo erişimi aldıktan sonra klonlayın ve bağımlılıkları yükleyin:

```bash
git clone <ekip-tarafından-sağlanan-depo-url>
cd aivex
pip install -r requirements.txt
```

## Ortam Yapılandırması

Örnek ortam dosyasını kopyalayın:

```bash
cp .env.example .env
```

Zorunlu değişkenler:

| Değişken | Açıklama |
|----------|----------|
| `DB_HOST` | MySQL sunucusu (varsayılan: `localhost`) |
| `DB_PORT` | MySQL portu (varsayılan: `3306`) |
| `DB_NAME` | Veritabanı adı |
| `DB_USER` | Veritabanı kullanıcısı |
| `DB_PASSWORD` | Veritabanı şifresi |

İsteğe bağlı değişkenler:

| Değişken | Açıklama |
|----------|----------|
| `API_TOKEN` | Eye API için Bearer token (tanımsız = kimlik doğrulama devre dışı) |
| `GOVERNOR_KILL_SWITCH` | Sinyal yayımını devre dışı bırakmak için `1` olarak ayarlayın |

## Sistemi Çalıştırma

**Her şeyi başlatın (7/24 denetimli mod):**
```bash
python Main.py
```

**Tek bir modülü bir kez çalıştırın (test için):**
```bash
python -m watchdog.runners.module_runner news --mode once
```

**Yalnızca Eye API'yi başlatın:**
```bash
python -m uvicorn eye.main:create_app --factory --port 8001
```

## Kurulumu Doğrulama

Sistemi başlattıktan sonra Eye API sağlık uç noktasını kontrol edin:

```bash
curl http://localhost:8001/health
```

Beklenen yanıt:
```json
{ "status": "ok", "version": "<mevcut-sürüm>" }
```

## Veritabanı Kurulumu

AIVEX ilk çalıştırmada gerekli tabloları otomatik olarak oluşturur. OHLCV verileri için geçmiş verileri
doldurmak üzere alma komut dosyasını bir kez çalıştırın:

```bash
python Ingest_ohlcv.py
```
